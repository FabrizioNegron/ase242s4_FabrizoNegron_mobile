#  Aplicativo Móvil - Expediciones Lunahuaná

##  Descripción del Proyecto
Este proyecto consiste en el desarrollo de un aplicativo móvil para el negocio turístico "Expediciones Lunahuaná", el cual permitirá a los clientes visualizar actividades, realizar reservas y compartir sus experiencias mediante reseñas y publicaciones con fotos.



##  Definición del Problema
Actualmente, los clientes no cuentan con una plataforma móvil que les permita acceder fácilmente a la información de actividades turísticas, realizar reservas de manera rápida ni compartir sus experiencias, lo que limita la interacción con el negocio.



##  Usuarios Involucrados
- **Clientes:** Usuarios que desean explorar actividades, reservar y compartir experiencias.  
- **Administrador:** Encargado de gestionar la información desde el sistema web.


##  Objetivos del Aplicativo
- Visualizar actividades disponibles  
- Realizar reservas  
- Consultar horarios  
- Publicar reseñas  
- Compartir experiencias con fotos  


##  Requerimientos Funcionales
- Registro de usuarios  
- Inicio de sesión  
- Visualizar actividades  
- Ver detalle de actividades  
- Consultar horarios disponibles  
- Realizar reservas  
- Ver estado de reservas  
- Publicar reseñas  
- Visualizar reseñas  
- Publicar experiencias (posts con fotos)  

## Requerimientos No Funcionales
- Seguridad en la autenticación  
- Interfaz amigable  
- Buen rendimiento  
- Alta disponibilidad  
- Escalabilidad  
- Integración con API REST  


##  Historias de Usuario

### 1. Página de Actividades
**Como** usuario **quiero** visualizar las actividades disponibles, **para** elegir una experiencia turística adecuada  
- Estimación: 4h  
- Valor: 90  
- Dependencia: Ninguna  


### 2. Detalle de Actividad
**Como** usuario **quiero** ver el detalle de una actividad, **para** conocer información completa antes de reservar  
- Estimación: 3h  
- Valor: 85  
- Dependencia: Página de Actividades  


### 3. Reservar Actividad
**Como** usuario **quiero** realizar una reserva, **para** asegurar mi participación  
- Estimación: 6h  
- Valor: 100  
- Dependencia: Detalle de Actividad  


### 4. Publicar Reseña
**Como** usuario **quiero** dejar una reseña, **para** compartir mi experiencia  
- Estimación: 4h  
- Valor: 80  
- Dependencia: Reservar Actividad  


### 5. Publicar Experiencia
**Como** usuario **quiero** publicar fotos y comentarios, **para** mostrar mi experiencia  
- Estimación: 5h  
- Valor: 85  
- Dependencia: Publicar Reseña
